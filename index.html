MT 启动页 URL 生成

生成白屏开关型启动页地址。开关文本托管在 app-gonow，返回 0~url / 1~url。

拼成： https://lwei1992.github.io/app-gonow/<path>/

填写后直接请求该地址，忽略 path。

启动页 URL

点击生成

接入说明

1. 把生成的 URL 写进 App 启动 WebView。
2. 请求开关文本：0~… → startAPP； 1~https://… → scanPrivacyPolicy 打开第二个参数。
3. 切回前台时若已是 1，会再次用缓存 link 打开。
4. 模板：welcome.html
