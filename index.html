MT 启动页 URL 生成

生成白屏开关型启动页地址（querySwitch），托管于 GitHub Pages。 App 内 WKWebView 仍使用 startAPP / scanPrivacyPolicy。

对应接口：…/querySwitch?key=你的 Bundle ID

一般不用改；仅在接口域名变更时填写完整 querySwitch 地址（不含 ?key=）。

启动页 URL

填写 Bundle ID 后生成

接入说明

1. 把生成的 URL 写进 App 的启动 WebView 地址。
2. 页面逻辑：请求开关接口 → status === "open" 时 scanPrivacyPolicy 打开 data.link，否则 startAPP 进主界面。
3. 切回前台时若已是 open，会再次用缓存 link 调起隐私页。
4. 在线模板： welcome.html
